**AI assistance**

If AI tools meaningfully assisted a contribution, add `Assisted-by: AI` to each assisted commit and as a standalone final line in the PR description.
To opt into the local commit-message helper, run `git config core.hooksPath .github/hooks` and set `PDPP_AI_ASSISTED=1` when committing.
