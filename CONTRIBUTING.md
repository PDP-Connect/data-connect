## AI assistance

Building with AI is welcome. If AI helped meaningfully, add an `Assisted-by: AI`
trailer to each assisted commit and as a standalone final line in the PR description,
so reviewers can calibrate their scrutiny. It is vendor-neutral and sits alongside
your DCO sign-off. We review contributions on whether they are good, not how they
were made.

To opt into the local commit-message helper, run `git config core.hooksPath .github/hooks`
and set `PDPP_AI_ASSISTED=1` when committing.
