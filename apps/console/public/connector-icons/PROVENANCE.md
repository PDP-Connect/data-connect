# Connector icon provenance

The console bundle uses the manifest-declared SVG files from
[PDP-Connect/data-connectors](https://github.com/PDP-Connect/data-connectors)
revision `23aee3aaeafad3a804d504e8614763f7845add60`. Their connector keys, canonical IDs, source paths, and SVG markup are recorded in the generated
`sanitized-assets.json` bundle under the console library. The bundle is checked
with the console SVG allowlist before it reaches the shared icon renderer.
