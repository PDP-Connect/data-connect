# Quality artifacts

The files in this directory (`inventory/`, `packets/`, `receipts/`, `claims.jsonl`, `cost.jsonl`, `hone.yaml`) are generated by the external hone tool. Nothing in this repository reads them at run time.

`$HONE_ROOT` in the `command` fields of `packets/*.yaml` is the path to a checkout of that hone tool. Run the commands from the repository root.

`repo_root` and `git_root` in `inventory/meta.json` are relative to the git root.

On the change that removed personal paths, absolute paths in recorded commands (`claims.jsonl`, the packets' evidence and `outcome.evidence_receipts`, and the `# command:` headers in `receipts/*/baseline-*.txt`) were rewritten to repo-relative form. The commands are otherwise as executed. The recorded digests and exit codes are from the original runs.

`test/quality-artifacts-repo-relative.test.ts` fails if a tracked artifact here records an absolute filesystem path.
